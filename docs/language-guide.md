# Kern Language Guide

Welcome to the Kern language! Kern combines the elegance of Python with the power of systems programming, giving you a language that grows with your ambition—from simple scripts to complex applications.

## 🎯 What makes Kern special?

**🐍 Python-like readability** with **⚡ compiled performance**
**🔧 System-level access** without **📦 complex build systems**
**🚀 Modern features** like async/await and decorators
**🛡️ Trust-based security** - you control the safety level

---

## 📚 Core Language Features

### Basic Syntax (familiar and clean)

```kern
// Variables - use let for immutable, var for mutable
let name = "Kern"
var counter = 0

// Functions - simple and expressive
def greet(who) {
    return "Hello, " + who + "!"
}

// Control flow - clean and readable
if counter > 0 {
    print("Counter is positive")
} else {
    print("Counter is zero or negative")
}

// Loops - both for and while supported
for i in range(5) {
    print("Iteration: " + str(i))
}
```

### Data Structures

```kern
// Arrays - dynamic and flexible
let numbers = [1, 2, 3, 4, 5]
let first = numbers[0]  // 1
numbers.push(6)         // Add to end

// Maps/Dicts - key-value pairs
let person = {
    "name": "Alex",
    "age": 30,
    "skills": ["Kern", "Python", "C++"]
}

// Access patterns
print(person["name"])           // Alex
print(person.get("city", "Unknown"))  // Unknown (with default)
```

### 🚀 Modern Language Features

#### Pattern Matching
```kern
match value {
    null => print("It's null")
    42 => print("The answer!")
    n when n > 0 => print("Positive: " + str(n))
    s when is_string(s) => print("String: " + s)
    _ => print("Something else")
}
```

#### Map Comprehensions
```kern
// Create maps with elegant syntax
let squares = { n: n * n for n in [1, 2, 3, 4] }
let evens_only = { n: n for n in [1, 2, 3, 4] if n % 2 == 0 }
```

#### Pipeline Operator
```kern
// Chain operations cleanly
import("lib/kern/funtools.kn")

let result = data
    |> filter(x => x > 0)
    |> map(x => x * 2)
    |> reduce((a, b) => a + b, 0)
```

#### Spread and Optional Chaining
```kern
def sum_all(a, b, c, d) {
    return a + b + c + d
}

let tail = [20, 30]
let result = sum_all(10, ...tail, 40)  // 100

// Optional chaining prevents null errors
let value = obj?.nested?.property ?? "default"
```

## 🎮 Kern's Unique Capabilities

### Async/Await for Concurrency
```kern
// Define async functions
async def fetch_data(url) {
    let response = await http_get(url)
    return parse_json(response)
}

// Use them naturally
let data = await fetch_data("https://api.example.com")
print("Got data: " + str(data))
```

### Decorators for Metaprogramming
```kern
// Command decorator - built into Kern
@command("analyze", description="Analyze files")
def analyze_command(ctx, args) {
    let files = list_files(args["directory"] ?? ".")
    return {"count": len(files), "analyzed": true}
}

// Event decorator - for reactive programming
@event("on_file_change", priority=50)
def handle_file_change(ctx, payload) {
    print("File changed: " + payload["path"])
    process_file(payload["path"])
}
```

### System-Level Access
```kern
// FFI - call C libraries directly
let lib = ffi_open("libc.so.6")
let result = ffi_call(lib, "printf", ["Hello from C!\n"])

// Process management
let process = spawn("ls", ["-la"])
let output = wait_for_process(process)
print("Process output: " + output)

// File system operations
let files = list_dir("./")
for file in files {
    if file.size > 1024 {
        print("Large file: " + file.name)
    }
}
```

### Unsafe Blocks for Maximum Control
```kern
// When you need direct memory access
unsafe {
    let ptr = allocate_memory(1024)
    defer free_memory(ptr)
    
    // Direct memory manipulation
    memset(ptr, 0, 1024)
    let data = cast_to_int_array(ptr, 256)
    
    // Work with data...
    process_array(data)
}
```

## 📦 Modules and Imports

```kern
// Import standard library modules
import("math")

import("lib/myproject/utils")
```

## 🛠️ Development Tools

### Compilation and Checking
```bash
# Compile without running (syntax/type checking)
kern --check script.kn

# See the AST (for learning/debugging)
kern --ast script.kn

# View generated bytecode
kern --bytecode script.kn

# Run with debug information
kern --debug script.kn
```

### Built-in Linting and Analysis
```bash
# Scan for common issues
kern --scan script.kn

# Type checking (when enabled)
kern --strict-types script.kn

# Performance profiling
kern --profile script.kn
```

## 🔒 Trust and Security Model

Kern's philosophy is **"trust the programmer"** by default:

- **No artificial sandboxes** - you get full system access
- **Explicit safety controls** - use flags when you need constraints
- **Clear responsibility** - you control what your code can do

### Runtime Safety Options
```bash
# Restrict dangerous operations
kern --no-ffi script.kn              # Disable FFI calls
kern --no-file-access script.kn       # Restrict file I/O
kern --sandbox script.kn              # Maximum restrictions

# Allow everything (default)
kern script.kn                        # Full trust
```
