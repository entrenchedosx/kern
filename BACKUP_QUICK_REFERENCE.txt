🚀 FIRST TIME SETUP (Do This Once)
================================================================================

1. Install rclone to exact path:
   Download: https://rclone.org/downloads/
   Extract to: E:\rclone\rclone.exe

2. Configure Google Drive:
   E:\rclone\rclone.exe config
   - Create new remote named: gdrive
   - Type: Google Drive
   - Authenticate with browser

3. Verify setup:
   E:\kerncode\verify_backup_setup.bat

================================================================================

   E:\kerncode\backup_kern.bat

Method 3 - Command line:
   cd E:\kerncode

📊 CHECKING BACKUPS
================================================================================

View current backup number:
   type E:\kerncode\backup\counter.txt

View operation log:
   type E:\kerncode\backup\backup.log

List backups on Google Drive:
   E:\rclone\rclone.exe ls gdrive:/KernBackups

Check total backup size:
   E:\rclone\rclone.exe size gdrive:/KernBackups

================================================================================

🆘 TROUBLESHOOTING
================================================================================

Problem: "rclone not found"
Fix: Install rclone to E:\rclone\rclone.exe

Problem: "Remote 'gdrive' not configured"
Fix: Run E:\rclone\rclone.exe config

Problem: "Access Denied"
Fix: Run as Administrator

Problem: "Upload failed"
Fix: Check internet connection

Run diagnostics:
   E:\kerncode\verify_backup_setup.bat
